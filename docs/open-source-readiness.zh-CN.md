# 开源评估与首发验收

核验日期：2026-10-26。本文记录 Alpha 的能力边界；是否公开以 GitHub Release 为准。

## 判断

可以发展为开源项目，现阶段适合定位为 **机器人仿真场景包生成工具的早期原型**。
不能宣传为已经实现了“世界模型自动生成可执行机器人任务”的系统。
成为受欢迎的项目需要可复现的实际用途与持续维护，不能通过宣传保证 Star 数。

建议长期定位：**把自然语言任务编译成可执行、可验证、可复现的机器人仿真任务。**
面向机器人研究者、仿真工程师、具身智能教学与评测开发者。Cosmos 是模型后端，
价值应建立在任务结构、执行器和验证报告上，避免只成为模型 API 的包装。

## 本次核验

## 首发版本建议

### 原型预览版

- 修正文档、片尾、仓库描述中的能力承诺，不写“完整闭环”“任意任务”“物理准确”。
- 给出无需 GPU 的本地生成与校验路径，将 Cosmos 请求作为独立可选项。
- 清楚注明机器人、控制器、任务判定和原生 MotrixSim 执行未实现。
- 发布前完成自有代码权属和第三方来源检查，应用真正的开源 LICENSE。
- 在全新 Linux/macOS 环境跑通安装，保存版本、命令、退出码和报告。

### 正式演示版

首发场景收敛到一个固定机械臂的桌面抓取与放置，先完整做成一个场景。

1. 接入许可明确的真实机械臂模型、关节、执行器、夹爪和动态物体。
2. 实现 reset、step、控制器和失败状态；不能通过移动 mesh 假装抓取。
3. 让成功判定读取物体位姿、区域和稳定时间；同时展示一次失败。
4. 明确模型在流程中的作用。模型若只生成视频，就只称参考视频；
   若要称模型驱动，须验证模型输出被任务编译器实际消费，并与规则基线比较。
5. 保存一次真实 Cosmos 请求和可解码的视频、模型版本、seed、耗时、硬件。
   请求中去除凭据，失败直接报告，不自动降级成成功。
6. 在原生 MotrixSim 指定版本里导入、运行、reset 并录制证据；
   同时保留 MuJoCo 路径，让不使用 MotrixSim 的开发者也能复现。
7. 建议用 20 个固定 seed 报告结果分布和失败原因；这是验收建议，当前无成绩。

机器人模板、任务参数和后端边界稳定后，再增加推物体、分类放置等场景。
没有上述结果，不宜为了宣传一次性扩展大量机器人和任务类型。

## 代码发布前需要修复的问题

- **覆盖保护已修复**：拒绝已有文件、目录与符号链接；任务名只能是受限的单个路径组成部分。
  重复生成需使用新名称或新输出根目录，不提供自动删除旧输出的选项。
- **动力学表示**：movable 标记没有对应 free joint；静态碰撞 mesh 聚合多个物体，
  引擎的凸包处理可能改变真实接触空间；需按实体构建并做接触测试。
- **视觉保真**：本次 MuJoCo 渲染还暴露了聚合场景的视觉表现问题，
  需要逐物体对照 OBJ、引擎载入结果与期望画面，不能仅依赖 `valid: true`。
- **材质一致性**：OBJ 写 `mtllib scene.mtl`，实际导出 `material.mtl`，
  并且没有 `usemtl`；要修正引用和子目录相对路径。
- **视频有效性**：目前只验证 base64 和非空字节；应验证 MP4 可解码及内容类型。
- **模型接口**：Reasoner、NIM JSON、vLLM-Omni 原生 MP4 三者不能混称。
- **移植性**：已去除默认个人绝对路径；Real2Motrix 导入脚本直接依赖其内部 DB API，
  需要固定兼容版本或改成公开导入契约。
- **用户边界**：启动脚本已默认绑定回环地址，且不再允许访问根目录媒体。
  输入大小、外部 URL 和服务认证仍需要部署者进一步限制。
- **交付信息**：CI 是本次新增配置，尚无远端 Actions 运行结果；不能挂虚假的通过徽章。

## 许可与发布范围

自有源码采用 Apache-2.0，根目录包含 LICENSE、NOTICE 与第三方来源说明，
包元数据已同步。第三方模型、素材及仿真器不包含在该源码许可内。

使用或分发 Cosmos3 Nano 材料前，须核对具体 revision 的模型卡、许可和来源声明。
不要将自己的代码许可覆盖到 NVIDIA 权重、上游演示素材或其他机器人的资产上。
本次片子只使用本项目新生成的几何与本机合成配音，没有使用上游模型示例视频。

`vendor/`、生成输出、环境文件和凭据不进入源码发布。
源码和发布附件需分别执行凭据检查；扫描未发现匹配不等于完整安全审计。

## 获取用户与贡献者

先请 5 位目标开发者从空环境复现，记录首次成功时间、安装失败与缺失功能。
首屏视频展示实际运行结果，README 提供一条最短命令和完整输出示例。
公开问题列表应包含边界清晰的小任务，例如材质引用、参数化和错误报告。
按可复现率、真实使用反馈、贡献 PR 和维护响应时间迭代；Star 作为结果观察。

现阶段只以“实验性 Alpha / 原型预览”发布；完整任务演示须等待执行闭环验收。
